# 자기소개표_phone

폰 화면 모양의 자기소개 틀을 브라우저에서 바로 편집하고 PNG로 저장하는 편집기입니다.

## 사용 방법

1. 왼쪽 패널에서 이름, 아이디, 성향, 말풍선, ABOUT 내용을 입력합니다.
2. 이미지 칸에 사진을 올리고, 미리보기에서 드래그해 위치를, 마우스 휠이나 두 손가락으로 크기를 맞춥니다.
3. 말풍선 개수(0~3개), 테마 색상, 글씨체를 원하는 대로 바꿉니다.
4. **PNG 저장**을 누르면 1080 × 1350(또는 2160 × 2700) 이미지가 저장됩니다.
5. 나중에 이어서 작업하려면 **작업 파일 저장**으로 .json 파일을 받아 두세요.

말풍선 본문에서 `**굵게**`로 감싸면 굵은 글씨, `==강조==`로 감싸면 강조색 글씨가 됩니다.

## 틀 사용 안내

- **틀 사용 불가 장르 및 캐릭터:** 엘소드 아인, 러브앤딥스페이스 기욱, 진격의 거인, 귀멸의 칼날
- 원형을 알아볼 수 있는 선에서 자유롭게 수정하셔도 괜찮습니다.
- **출처 삭제 금지!**
